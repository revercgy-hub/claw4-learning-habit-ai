## 二、P0 阻断项 (必须先解决)

### 1. IDF 工具链未安装 — 最关键

`C:\Users\rever\.espressif` 目录不存在, 意味着以下全部缺失:

- `xtensa-esp-elf` / `riscv32-esp-elf` 编译器
- IDF 自带 cmake / ninja
- Python 虚拟环境 (python_env) 及 pip 依赖包

**修复:**
```bash
# 在 Git Bash 中执行 (约需下载 1.5~2 GB, 视网络 10~40 分钟)
cd /e/workbuddy/学习习惯培育AI/toolchains/esp-idf-v5.5.4
./install.sh esp32p4
```
或 PowerShell:
```powershell
cd E:\workbuddy\学习习惯培育AI\toolchains\esp-idf-v5.5.4
.\install.ps1 esp32p4
```
> 只装 esp32p4 目标即可 (Claw4 主控); C5 从机不在本机编译范围。

### 2. IDF 环境入口未配置

每次构建前需激活 IDF 环境:
```bash
cd /e/workbuddy/学习习惯培育AI/toolchains/esp-idf-v5.5.4
source export.sh          # Git Bash
# 或 PowerShell: .\export.ps1
```
> 建议后续做一个一键入口脚本 (`esp-idf-env.ps1`), 把 IDF_PATH 与 idf.py 注入当前会话。

### 3. 仓库路径含中文 — 构建隐患

`E:\workbuddy\学习习惯培育AI\vendor\MetalioClaw4` 含中文 + 空格, CMake/Ninja 在 Windows 上对非 ASCII 路径兼容性差, esp32p4 全量构建极易失败。

**建议:** 将仓库迁移到纯 ASCII 路径, 例如:
```
D:\claw4\MetalioClaw4
```
(esp_claw_bin 分区固件与出厂固件一并迁移)

## 三、P1 建议项

### 4. 串口驱动 — 等设备到手前提前备好

当前系统无任何 CP210x / CH340 / FTDI 驱动记录。Claw4 有 4 个串口:

| 串口 | 用途 | 驱动 |
|------|------|------|
| USB JTAG/serial debug unit | P4 主控调试口 | Windows 10/11 自带 CDC 驱动, 一般免驱 |
| CH340K | 蓝牙 | 需 WCH CH340 驱动 (官网下载) |
| 4G AT / 4G log | 4G 模组 | 视模组而定, 多为 USB 串口 |

**建议:** 提前下载 CH340 驱动 (https://www.wch.cn/downloads/CH341SER_EXE.html) 备用, 设备到手插上后逐个确认。
