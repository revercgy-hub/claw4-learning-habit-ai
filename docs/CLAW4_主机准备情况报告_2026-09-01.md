真机到货前禁止为消除此警告而修改 partition table。需要先确认实际启动分区、官方 OTA 设计、恢复镜像和刷写流程。

## 7. 真机到货前仍不能确认的项目

以下项目应标记为 `DEVICE_VERIFY_REQUIRED`，不能标记为安装失败：

- Windows 实际枚举出的 USB 设备与 COM 口数量；
- P4 调试口的实际 COM 号；
- 是否需要额外的 CH340、CP210x、FTDI 或模组专用驱动；
- 实机屏幕驱动是 NV3051F 还是其他 SKU；
- 触摸控制器、Flash、PSRAM、C5 ESP-Hosted、SD、音频、摄像头和电源功能；
- 当前实机使用的 boot partition 和 OTA 恢复路径。

不应硬编码“设备通电后一定出现 4 个串口”。正确方法是记录实际枚举变化，再按设备描述符识别 P4 的 `USB JTAG/serial debug unit`。P4 主调试接口通常使用普通可传数据的 USB-C 线，不需要专用 JTAG 线。

## 8. 真机到货后的首轮操作

1. 使用确认可传数据的 USB-C 线连接主机与 Claw4。
2. 在设备管理器记录连接前后的 USB/COM 枚举变化。
3. 识别 P4 的 `USB JTAG/serial debug unit`，记录实际 COM 号。
4. 在不改固件的前提下保存完整启动日志、SKU、板号和接口照片。
5. 依次执行 Bring-up Stage 1：B001、B002、B003、B004、B005、B009、B013。
6. 在确认官方基线、恢复方式和实际分区前，不刷自定义固件、不测试 OTA、不修改 BSP/屏幕时序/PSRAM/partition table。
